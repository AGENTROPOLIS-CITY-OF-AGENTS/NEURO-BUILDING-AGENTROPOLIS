# AGENTROPOLIS

**A city built for agents.**

The Intelligence Grid — a spatial operating system where the city is the interface.

[Live](https://agentropolis.grok.me) · [HERMES CITY](https://github.com/AGENTROPOLIS-CITY-OF-AGENTS/HERMES-CITY) · [DOCK](https://github.com/AGENTROPOLIS-CITY-OF-AGENTS/AGENTROPOLIS-DOCK)

## Stack

- TanStack Start + React 19
- Three.js / R3F city (client-only)
- Tailwind v4
- Canonical design system: OBSIDIAN `#05070A` · CYAN `#19E6E6` · RED `#FF2A2A`

## Quantize law

AGENTROPOLIS quantizes compute, visuals, models, and information density together.

Tiers: `FULL` → `ADAPTIVE` → `LITE` → `MINIMUM`

## Architecture

```
DESIGN SYSTEM → APPLICATION → DISTRICTS → BUILDINGS → AGENTS → TASKS / RECEIPTS
```

Governance corridor: IDENTITY → MANDATE → PLAN → POLICY → EXECUTE → RECEIPT → AUDIT

3D worlds never load on the server. The HTML shell is quantized. The city hydrates in the browser.
